# Pill Reminder Robot

Helps grandparents remember to take pills on time.

Built on Android phone (Pydroid 3).

 How it works:
- Stores pill schedule (08:00, 14:00, 20:00)
- Beeps when it's time to take pills
- Saves TAKEN/MISSED to log file
- Shows daily report

Tech:
Python, OOP, datetime, File handling
